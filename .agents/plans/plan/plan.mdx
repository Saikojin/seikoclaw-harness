# SeikoClaw Task Plan

## Task Description
# Master Task Checklist: Gameplay Atlas Integration & Offline Mechanic Intelligence

## 🎯 Goal
Scrape, index, and integrate the 280 gameplay mechanics from [Gameplay Atlas](https://gameplayatlas.loopyhop.com/) into an offline SQLite FTS5 database (`data/gameplay_atlas.db`), build a high-performance CLI query lever (`scripts/gameplay_atlas.py`), author a dedicated agent skill (`gameplay-atlas`), and integrate mechanic retrieval directly into `game-forge` (Stages A, B, and C) and `game-router`.

---

## 📋 Execution Roadmap

### Phase 1: Ingestion Engine & Offline Database
- [ ] **Task 1.1: Author Idempotent Sync Scraper (`scripts/sync_gameplay_atlas.py`)**
  - **Objective**: Build an automated scraper that fetches the live site root, dynamically extracts the content-hashed asset directory (e.g. `/assets/<hash>/`), downloads `index.json`, uses a concurrent worker pool to fetch all 280 mechanic JSON files, populates normalized SQLite tables with an FTS5 full-text index in `data/gameplay_atlas.db`, and saves the raw JSON files into `data/gameplay_atlas/raw/`.
  - **Validate**: `python scripts/sync_gameplay_atlas.py`
  - **[GATE: QA]**: SQLite database contains exactly 280 mechanics across 28 systems, with full FTS5 search index and 0 HTTP errors.

- [ ] **Task 1.2: Database Integrity & FTS5 Verification Suite**
  - **Objective**: Author and run a test script (`tests/test_gameplay_atlas_db.py`) verifying that the SQLite schema, tag associations, loop steps, parameter definitions, shipped game cases, and FTS5 search queries return complete and accurate records.
  - **Validate**: `python -m unittest tests/test_gameplay_atlas_db.py`
  - **[GATE: QA]**: 100% test pass asserting all 280 records, table relationships, and FTS5 search operators.

---

### Phase 2: CLI Query Lever (`scripts/gameplay_atlas.py`)
- [ ] **Task 2.1: Implement High-Performance CLI Tool (`scripts/gameplay_atlas.py`)**
  - **Objective**: Create a zero-dependency CLI interface with subcommands:
    - `search <query>` (FTS5 search with `--system`, `--tag`, `--scope`, `--json` flags)
    - `get <id>` (detailed formatted mechanic card or raw json)
    - `systems` (list all 28 systems with counts)
    - `tags` (list all 16 tags with counts)
    - `combine <system1> <system2>` (cross-system mechanic synergy ideas)
    - `prototype-recipe <id>` (extracts `firstStep`, `pitfall`, and `test` playtest criteria)
    - `cases <game_name>` (find all mechanics implemented by a shipped game, e.g. Factorio, Celeste)
    - `random` (serendipitous mechanic generator with optional `--system` filter)
  - **Validate**: `python scripts/gameplay_atlas.py search "stamina" && python scripts/gameplay_atlas.py get combat-stamina-budget`
  - **[GATE: QA]**: All 8 subcommands execute in <10ms and return expected structured outputs.

---

### Phase 3: Agent Skill & Routing Integration
- [ ] **Task 3.1: Author `gameplay-atlas` Skill (`.agents/skills/gameplay-atlas/SKILL.md`)**
  - **Objective**: Create `.agents/skills/gameplay-atlas/SKILL.md` with standard frontmatter, providing agents with actionable recipes for mechanic ideation, game loop design, player dilemma analysis, and prototyping test plans using `scripts/gameplay_atlas.py`.
  - **Validate**: `python -c "from pathlib import Path; assert Path('.agents/skills/gameplay-atlas/SKILL.md').exists()"`
  - **[GATE: QA]**: Valid frontmatter, clean Markdown formatting, and explicit command contracts.

- [ ] **Task 3.2: Expand Routing Benchmark Dataset with Gameplay Atlas Queries**
  - **Objective**: Add canonical mechanic lookup and prototyping queries to `evals/routing/routing_cases.json`, then execute the routing evaluation harness to prove accurate routing and zero skill collisions.
  - **Validate**: `python scripts/eval_skill_routing.py --cases evals/routing/routing_cases.json`
  - **[GATE: QA]**: Routing benchmark achieves 100% accuracy with zero overlap collisions.

---

### Phase 4: Game Forge & Game Router Ecosystem Integration
- [ ] **Task 4.1: Integrate Gameplay Atlas into `game-router` and `game-forge`**
  - **Objective**: Update `.agents/skills/game-router/SKILL.md` and `.agents/skills/game-forge/SKILL.md` so that:
    - `game-router` dispatches `gameplay-atlas` for mechanic lookup and loop formulations.
    - `game-forge` Stage A automatically cross-references Gameplay Atlas for 10s/30s/5m loops and locked game cases.
    - `game-forge` Stage B (`scope-surgeon`) utilizes `prototype-recipe` to extract `firstStep` and `pitfall`.
    - `game-forge` Stage C (`game-systems-modeler`) imports `parameters` into `docs/design/balance.json`.
  - **Validate**: `python -c "text = open('.agents/skills/game-forge/SKILL.md', encoding='utf-8').read(); assert 'gameplay-atlas' in text"`
  - **[GATE: QA]**: Game Forge and Game Router workflows explicitly bind Gameplay Atlas.

- [ ] **Task 4.2: End-to-End System Diagnostics & Health Verification**
  - **Objective**: Run `seikoclaw doctor` to certify all databases, skills, and routing benchmarks pass with green status.
  - **Validate**: `python seikoclaw.py doctor`
  - **[GATE: QA]**: All diagnostic checks pass.
