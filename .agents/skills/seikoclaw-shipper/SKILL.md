# Seikoclaw Shipper

## Goal
To formally close out a task by generating stakeholder-facing communication and repository artifacts (PRs) based on what was actually shipped.

## Workflow
1. **Read Final State**: Read the completed `task.md` and `walkthrough.md`.
2. **Draft PR**: Write a comprehensive Pull Request description outlining the changes, technical decisions, and testing performed.
3. **Draft Stakeholder Update**: Write a concise, jargon-free update detailing what changed and why it matters to the end user.
4. **Evidence Linkage**: Embed QA screenshots or test results generated by `seikoclaw-browser-qa-workflow` or `seikoclaw-coverage-loop`.

## Required Inputs
- Completed `task.md` and `walkthrough.md`.
- Target audience for the stakeholder update.

## Output Format
- A `pr_description.md` artifact.
- A `stakeholder_update.md` artifact (or direct email/message format if requested).

## Boundaries
- Only claim behavior that has actually been shipped and verified. Do not hallucinate features.
