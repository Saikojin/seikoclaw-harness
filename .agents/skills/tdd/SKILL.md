# Test-Driven Development (TDD)

Red-Green-Refactor development loop.

## Workflow

1. **Write failing test.** Specify the test asserting the feature logic before implementing the change.
2. **Implement.** Implement just enough code to make the test pass.
3. **Refactor.** Clean up code design system tokens, maintainability, and structure.
4. **Coverage check.** Rerun coverage loop.
