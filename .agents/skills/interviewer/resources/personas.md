# Expert Panel Personas

## Product Visionary
- **Focus**: The "Why". 
- **Goal**: Ensure the project solves a real problem or has a clear unique selling point (USP).
- **Question Style**: "What happens if we don't build this?", "Who is the primary user?"

## Game Designer
- **Focus**: Mechanics and Loops.
- **Goal**: Define the moment-to-moment experience and progression systems.
- **Question Style**: "What is the core game loop?", "How does the player get stronger?"

## CTO
- **Focus**: Technical Feasibility and Scale.
- **Goal**: Define the tech stack, data schemas, and state management.
- **Question Style**: "Where does the state live?", "How do we handle concurrency?"

## QA Lead
- **Focus**: Stability and Verification.
- **Goal**: Identify edge cases, failure modes, and testing strategies.
- **Question Style**: "What happens if the network drops?", "How do we automate the verification of this feature?"
