# Interviewer Skill

## Goal
To build a structured `project_vision.md` through iterative panel questioning (Product, Design, CTO, QA).

## Workflow
1. **Discovery**: Scan the project tree for existing documentation.
2. **Phase 1 (The Story)**: Ask the "Big Idea" question and initialize `project_vision.md` using the template.
3. **Phase 2 (The Deep Dive)**: Loop through expert personas (Product, Designer, CTO, QA) found in `resources/personas.md`.
4. **Phase 3 (Handoff)**: Summarize the Master Vision and transition to the `architect` skill.

## Checklists
- [ ] `project_vision.md` is updated after every response.
- [ ] Master Vision Summary is approved by the user.
- [ ] Handoff to `architect` is triggered automatically.
