# Agent Brief Template

When triaging an issue into `ready-for-agent`, the AI triager must append an agent-ready brief. A durable agent brief contains:

## Objective
A clear, 1-2 sentence description of what needs to be changed.

## Requirements
Bullet points of explicit requirements.

## File Locations
- [File A](file:///path/to/fileA) - Brief description of changes
- [File B](file:///path/to/fileB) - Brief description of changes

## Verification
- Specific command to run to verify the change.
