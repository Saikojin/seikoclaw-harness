# Shadowdark: Bard & Ranger Classes

Comprehensive rules and mechanics for the Bard and Ranger classes in the Shadowdark RPG system (designed by Kelsey Dionne / The Arcane Library).

## Core Class Overviews

| Class | Hit Die | Weapons | Armor | Core Archetype | Primary Mechanics |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Bard** | `d6` | Crossbow, dagger, mace, shortbow, shortsword, spear, staff | Leather, chainmail, shields | Lorekeeper, party face, scroll dabbler | `Presence` (Inspire/Fascinate), `Magical Dabbler`, `Bardic Arts` |
| **Ranger** | `d8` | Dagger, longbow, longsword, shortbow, shortsword, spear, staff | Leather, chainmail | Wilderness scout, tracker, survivalist | `Wayfinder` (Advantage checks), `Herbalism` (remedy preparation) |
