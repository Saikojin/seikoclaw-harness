# Game Prototype Builder

The **Game Prototype Builder** generates zero-dependency, single-file HTML5 playable games (`prototype.html`) that non-coding designers can double-click to open and play immediately in any web browser.

## Core Capabilities & Tech Stack

- **Target Engine**: Pure Vanilla HTML5 2D Canvas API + JavaScript (ES6). Zero external CDN dependencies or framework lock-in.
- **Audio Engine**: Web Audio API Procedural Synth (generates real-time retro sound effects: jumps, laser blasters, hits, explosions, coin picks without external `.wav` files).
- **Input Handling**: Full keyboard (WASD / Arrow keys / Space), mouse click/aim, and Gamepad API support.
- **Instrumentation & Tuning Panel**:
  - **Debug HUD**: Live FPS, session timer, action counters, death/restart trackers.
  - **Live Parameter Sliders**: On-screen collapsible panel allowing the designer to adjust live variables (e.g. `Gravity`, `MoveSpeed`, `AttackCooldown`, `ParryWindow`) and test feel changes in real time.
  - **Telemetry Export**: A "Copy Playtest Log" button that exports JSON session metrics to paste into the **Playtest Feedback Loop** (`/wayfinder` ticket 06).

## Inputs & Prerequisites

Consumes:
- `VERTICAL_SLICE_SPEC.md` generated by the Scope Surgeon (`scope-surgeon` skill).
- Core verbs, rules, and success conditions defined in the micro-slice.

## Output Specification

Creates `.scratch/<project>/prototype.html` (or `prototypes/prototype.html`):

1. **Self-Contained File**: CSS + HTML + JS all inside one `.html` file.
2. **Visual Style**: Clean retro vector art (geometric shapes with glow effects, particle effects for impacts, telegraph indicators for enemy attacks).
3. **Control Legend**: On-screen overlay showing controls.
4. **Instant Restart**: Press 'R' to instantly reset the 30–90s micro-loop.

## Workflow

1. **Read `VERTICAL_SLICE_SPEC.md`**: Extract the 1–2 player verbs, enemy/arena rules, and parameter variables.
2. **Generate Game Loop**:
   - `init()`: Canvas setup, Web Audio context, parameter state.
   - `update(dt)`: Movement physics, collision detection, game state machine.
   - `render()`: Canvas rendering, particle drawing, telegraph indicators.
   - `renderHUD()`: Draw debug overlay & parameter sliders.
3. **Verify Playability**: Execute local browser check or report file path to user.
4. **Handoff**: Direct designer to double-click `prototype.html`, play 5–10 rounds, tweak sliders, and invoke `/wayfinder` ticket 06 (`playtest-feedback-loop`).
