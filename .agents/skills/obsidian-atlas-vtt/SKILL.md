# Obsidian Atlas VTT Bridge & Scene Specification

The **`obsidian-atlas-vtt`** skill equips agents to parse, author, and manipulate Virtual Tabletop scenes, battlemaps, tokens, and campaign bundles inside Obsidian using the **Atlas VTT** plugin (`atlas-vtt/atlas-vtt`). It serves as the primary interop bridge between Obsidian campaign vaults, **Tablebuddy**, and **/game-forge**.

---

## 1. Scene File Format (`.atlasmap`)

Atlas VTT stores scenes as JSON inside `.atlasmap` files:

```json

    "version": 1,
    "background": "assets/maps/dungeon_level_1.webp",
    "grid": {
      "enabled": true,
      "visible": true,
      "snapToGrid": true,

      "size": 70,
```

## 2. Universal VTT (`.uvtt` / `.dd2vtt`) Ingestion

Atlas VTT provides an untrusted-input-safe importer for Universal VTT files generated by Dungeondraft, DungeonFog, and Dungeon Alchemist.

### Key UVTT Geometry Fields:
- `resolution.map_size`: `{ x: width_in_cells, y: height_in_cells }`
- `resolution.pixels_per_grid`: Grid cell width in pixels (e.g. `256` or `70`)
- `line_of_sight`: Array of wall segment coordinates `[[{x, y}, {x, y}], ...]`.
- `portals`: Array of doors/windows `{ position: {x, y}, bounds: [...], closed: boolean, freemove: boolean }`.
- `lights`: Array of light emitters `{ position: {x, y}, range: float, color: hex, intensity: float }`.

### UVTT Processing Constraints:
1. Max image resolution: 8192 px per side (one GPU texture).
2. Segment limits: Max 20,000 wall segments and 2,000 lights.
3. Closed portal = closed door. Open portal = window (blocks movement, transparent to sight/light).

## 3. Pinned Markdown Notes & Inline Dice

Atlas VTT embeds rich Obsidian Markdown directly onto the canvas:
- **Location Pins**: Clicking a pin opens the note in a floating sidecar without unmounting the canvas.
- **Wikilinks**: Note pins support full Obsidian `[[Internal Links]]`.
- **Inline Dice Syntax**: Writing standard dice syntax (`2d8+2`, `1d20+5`, `3d6`) inside a note or statblock renders as a clickable dice roll button that logs directly to the Atlas roll history.

## 4. Fantasy Statblocks Integration

Atlas VTT tightly integrates with the `Fantasy Statblocks` community plugin via frontmatter:

```markdown
---
name: Blood Olm
size: Medium
type: Beast
alignment: Neutral
ac: 12
hp: 14

speed: 30 ft., swim 40 ft.
stats: [10, 14, 15, 3, 12, 5]
damage_immunities: poison

  - name: Bite

---
```

## 5. Modular Campaign Bundles (`.atlas-collection.zip`)

As exemplified by `ByteMirror/atlas-vtt-cairn`, entire TTRPG systems and adventure modules are packaged as `.atlas-collection.zip` archives containing:
- `collection.json`: Metadata, grid defaults, and rules identifiers.
- `scenes/`: `.atlasmap` scene definitions.
- `assets/`: WebP maps and token images.
- `notes/`: Rules, player guides, room descriptions, and loot tables.
- `statblocks/`: Fantasy Statblocks layout and creature cards.

This bundle format is the recommended medium for Tablebuddy import/export and Game Forge TTRPG micro-slices.
